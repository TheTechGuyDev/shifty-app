# Shifty (working name)

House and multi-service marketplace app built with Flutter (Android, iOS, Web) and Supabase.

- Live web preview: https://thetechguydev.github.io/shifty-app/
- Rename the app: `lib/core/config/app_config.dart`
- Brand colours and fonts: `lib/core/theme/`

Every push to `main` builds the web app and deploys it to GitHub Pages.
